# Restaurant Practice

Create a professional, modern and mobile-friendly website for a fictional restaurant in Pakistan called "Spice House". Include: 1. A beautiful homepage with a hero section. 2. An About Us section. 3. A food menu with prices in PKR. 4. A gallery section. 5. A contact section with placeholder phone number and address. 6. A WhatsApp order button. 7. A responsive design for mobile and desktop. Use attractive food images, elegant typography, and a premium restaurant design. Make all navigation links work. Use clearly marked fictional contact details. Do not create fake customer reviews. I am a beginner, so make the website as easy to edit as possible.
